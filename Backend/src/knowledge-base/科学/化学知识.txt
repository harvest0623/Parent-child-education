# 化学知识

## 物质的分类

### 纯净物
由一种物质组成。
1. 单质：由同种元素组成的纯净物
   - 金属单质：铁、铜、铝等
   - 非金属单质：氧气、氮气、碳等
2. 化合物：由不同种元素组成的纯净物
   - 氧化物：由两种元素组成，其中一种是氧元素
   - 酸、碱、盐

### 混合物
由两种或多种物质混合而成。
- 空气、海水、合金等

## 元素

### 元素的概念
元素是具有相同核电荷数（即核内质子数）的一类原子的总称。

### 常见元素
1. 金属元素：钠(Na)、镁(Mg)、铝(Al)、铁(Fe)、铜(Cu)、锌(Zn)
2. 非金属元素：氢(H)、碳(C)、氮(N)、氧(O)、磷(P)、硫(S)

### 元素符号
- 一个字母：大写（如 H、C、N、O）
- 两个字母：第一个大写，第二个小写（如 Na、Mg、Al）

## 化学式

### 化学式的概念
用元素符号和数字的组合表示物质组成的式子。

### 常见物质的化学式
1. 氧气：O₂
2. 氮气：N₂
3. 水：H₂O
4. 二氧化碳：CO₂
5. 氯化钠：NaCl
6. 氧化铁：Fe₂O₃

### 化学式的意义
1. 表示一种物质
2. 表示物质的组成元素
3. 表示一个分子
4. 表示分子的构成

## 化学方程式

### 化学方程式的概念
用化学式表示化学反应的式子。

### 书写步骤
1. 写出反应物和生成物的化学式
2. 配平化学方程式
3. 注明反应条件
4. 标明生成物的状态

### 常见化学方程式
1. 碳燃烧：C + O₂ →点燃→ CO₂
2. 铁燃烧：3Fe + 2O₂ →点燃→ Fe₃O₄
3. 水电解：2H₂O →通电→ 2H₂↑ + O₂↑
4. 实验室制氧气：2H₂O₂ →MnO₂→ 2H₂O + O₂↑

## 常见的化学反应

### 化合反应
两种或两种以上物质生成另一种物质的反应。
- A + B → C

### 分解反应
一种物质生成两种或两种以上其他物质的反应。
- A → B + C

### 置换反应
一种单质和一种化合物反应生成另一种单质和另一种化合物的反应。
- A + BC → AC + B

### 复分解反应
两种化合物互相交换成分生成另外两种化合物的反应。
- AB + CD → AD + CB

## 酸碱盐

### 酸
电离时生成的阳离子全部是氢离子的化合物。
- 常见的酸：盐酸(HCl)、硫酸(H₂SO₄)、硝酸(HNO₃)

### 碱
电离时生成的阴离子全部是氢氧根离子的化合物。
- 常见的碱：氢氧化钠(NaOH)、氢氧化钙(Ca(OH)₂)

### 盐
由金属离子和酸根离子组成的化合物。
- 常见的盐：氯化钠(NaCl)、碳酸钠(Na₂CO₃)

### 酸碱指示剂
1. 石蕊试液：遇酸变红，遇碱变蓝
2. 酚酞试液：遇酸不变色，遇碱变红

## 金属活动性顺序

钾钙钠镁铝，锌铁锡铅氢，铜汞银铂金。

- 位置越靠前，活动性越强
- 排在氢前面的金属能与酸反应产生氢气
- 排在前面的金属能把排在后面的金属从其盐溶液中置换出来
