# 几何图形

## 平面图形

### 三角形
三角形是由三条线段首尾相连组成的封闭图形。
- 等边三角形：三条边都相等，三个角都是60度
- 等腰三角形：两条边相等，两个底角相等
- 直角三角形：有一个角是90度

### 四边形
四边形是由四条线段首尾相连组成的封闭图形。
- 正方形：四条边相等，四个角都是90度
- 长方形：对边相等，四个角都是90度
- 平行四边形：对边平行且相等
- 梯形：只有一组对边平行

### 圆形
圆形是由到定点距离等于定长的点组成的图形。
- 圆心：定点
- 半径：圆心到圆上任意一点的距离
- 直径：通过圆心且两端都在圆上的线段

## 立体图形

### 长方体
长方体有6个面，12条棱，8个顶点。
- 表面积 = 2×(长×宽 + 长×高 + 宽×高)
- 体积 = 长×宽×高

### 正方体
正方体是特殊的长方体，6个面都是正方形。
- 表面积 = 6×边长²
- 体积 = 边长³

### 圆柱体
圆柱体由两个相等的圆和一个侧面组成。
- 侧面积 = 2π×半径×高
- 体积 = π×半径²×高

### 圆锥体
圆锥体由一个圆和一个顶点组成。
- 体积 = (1/3)×π×半径²×高
